# 💳 Telegram Payment Bot

Telegram-бот для управления платежами с поддержкой повторяющихся платежей и автоматических напоминаний.

## 🚀 Возможности

- ✅ **Добавление платежей** через интерактивный пошаговый диалог
- 📋 **Просмотр списка** активных платежей
- 🔄 **Повторяющиеся платежи** с настройкой интервала и количества повторений
- ✅ **Отметка выполнения** платежей
- 🕓 **Перенос платежей** на произвольное количество дней
- ✏️ **Редактирование** платежей
- ❌ **Удаление** платежей
- 🔔 **Ежедневные напоминания** о платежах
- 📊 **Логирование** всех действий
- 👨‍💼 **Уведомления администратора** о важных событиях

## 🛠 Установка и настройка

### 1. Клонирование или создание проекта

Создайте папку проекта и поместите в нее все файлы.

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Создание Telegram-бота

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Сохраните токен - он понадобится на следующем шаге

### 4. Настройка переменных окружения

1. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```

2. Откройте `.env` и заполните:
   ```
   BOT_TOKEN=ваш_токен_от_BotFather
   ADMIN_ID=ваш_telegram_id
   ```

3. Чтобы узнать свой Telegram ID:
   - Напишите боту [@userinfobot](https://t.me/userinfobot)
   - Скопируйте ваш ID

### 5. Запуск бота

```bash
python bot.py
```

Бот готов к работе! 🎉

## 📖 Использование

### Команды

- `/start` - Запустить бота и показать главное меню

### Главное меню

- **➕ Добавить платеж** - Создать новый платеж
- **📋 Список платежей** - Посмотреть все активные платежи
- **📅 Платежи на сегодня** - Показать платежи, запланированные на сегодня
- **ℹ️ Помощь** - Справка по боту

### Процесс добавления платежа

1. **Название** - Введите название платежа (например, "Аренда квартиры")
2. **Дата** - Укажите дату в формате ДД.ММ.ГГГГ (например, 15.12.2024)
3. **Сумма** - Введите сумму в рублях (например, 50000 или 50000.50)
4. **Комментарий** - Добавьте комментарий или отправьте `-` для пропуска
5. **Тип платежа**:
   - **Однократный** - платеж произойдет один раз
   - **Повторяющийся** - платеж будет повторяться автоматически
6. Для повторяющихся платежей:
   - **Интервал** - укажите количество дней между платежами (например, 30)
   - **Количество повторений** - сколько раз повторить (0 = бесконечно)

### Управление платежами

Для каждого платежа доступны кнопки:

- **✅** - Отметить как выполненный
- **🕓** - Перенести на N дней
- **✏️** - Редактировать (в разработке)
- **❌** - Удалить

### Автоматические напоминания

Бот ежедневно в 9:00 отправляет список платежей на текущий день всем пользователям с активными платежами.

Изменить время можно в файле `config.py`:
```python
REMINDER_TIME = (9, 0)  # Часы, минуты
```

## 🗄 База данных

Бот использует SQLite базу данных с двумя таблицами:

### Таблица `payments`
Хранит информацию о платежах:
- `id` - уникальный идентификатор
- `name` - название платежа
- `user_id` - ID пользователя Telegram
- `date` - дата платежа
- `amount` - сумма
- `comment` - комментарий
- `status` - статус (active/completed)
- `is_recurring` - флаг повторяющегося платежа
- `interval_days` - интервал повторения
- `repeat_count` - количество оставшихся повторений
- `created_at` - дата создания

### Таблица `logs`
Хранит логи всех действий:
- `id` - уникальный идентификатор
- `user_id` - ID пользователя
- `payment_id` - ID связанного платежа
- `action` - тип действия
- `details` - детали действия
- `created_at` - время действия

## 📊 Логирование

Все действия логируются в:
- **Консоль** - для мониторинга в реальном времени
- **Файл bot.log** - для последующего анализа
- **База данных** - в таблицу `logs`

Типы логируемых действий:
- Добавление платежа (`add`)
- Выполнение платежа (`complete`)
- Перенос платежа (`postpone`)
- Удаление платежа (`delete`)

## 👨‍💼 Уведомления администратора

Администратор (указанный в `ADMIN_ID`) получает уведомления о:
- Добавлении новых платежей
- Удалении платежей
- Переносе платежей

## 🐛 Отладка

### Проблемы с запуском

1. Проверьте, что установлены все зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Убедитесь, что файл `.env` создан и содержит корректные данные

3. Проверьте логи в `bot.log`

### Бот не отвечает

1. Убедитесь, что токен бота правильный
2. Проверьте подключение к интернету
3. Перезапустите бота

### Не приходят напоминания

1. Проверьте настройку `REMINDER_TIME` в `config.py`
2. Убедитесь, что есть активные платежи на текущую дату
3. Проверьте логи на наличие ошибок отправки
